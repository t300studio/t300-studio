**⚠️ Windows SmartScreen Notice**

Since T300 Studio is a new, independently developed application and its installer isn't digitally signed yet, Windows may display a "Windows protected your PC" warning when launching it.

This can happen with new applications that haven't established a reputation with Microsoft SmartScreen.

Please only download T300 Studio from the official GitHub repository linked above. You're welcome to scan the installer with Windows Security before running it.

I'm looking into code signing for future releases to make the installation experience smoother and more trustworthy. ❤️
