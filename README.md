# 🏎️ T300 Studio

### Your wheel. Your settings. Your control.

**T300 Studio** is a free, independent Windows application designed to provide a modern, intuitive control and diagnostics experience for Thrustmaster racing wheels.

Built by a sim racer who wanted something better than the traditional control panel.

> ⚠️ **Early Development:** T300 Studio is still under active development. Some features are experimental, and only the T300RS has been physically tested so far.

---

## 📥 Download

**Latest version: 6.6**

**[Download T300 Studio](https://github.com/t300studio/t300-studio/releases/latest)**

### Installation

1. Download the latest Windows release from GitHub.
2. Run the T300 Studio installer.
3. Follow the installation instructions.
4. Launch T300 Studio using your desktop shortcut.
5. Connect your compatible Thrustmaster racing wheel.

**Requirements:**
- Windows PC
- Compatible Thrustmaster racing wheel
- Appropriate Thrustmaster drivers installed
- Internet connection for update checking and downloads

## ✨ Features

### 🎮 Wheel Control
- Adjustable steering rotation angle
- Force feedback strength adjustments
- Autocenter spring configuration
- Instant settings application
- Real-time steering wheel visualization
- Live button and input monitoring

### 🏁 Automatic Game Profiles
- Custom steering and force feedback settings for individual games
- Automatic game detection
- Automatic profile switching
- Restore desktop settings after closing games
- Import and export profiles

### 🔧 Pedal Calibration
- Real-time throttle, brake, and clutch monitoring
- Adjustable input deadzones
- Custom response curves
- Linear, Progressive, Aggressive, and S-curve presets
- Raw vs adjusted input comparison
- Optional vJoy integration for compatible games

### 🩺 Hardware Diagnostics
- Wheel centering accuracy tests
- Input stability monitoring
- Individual button testing
- Force feedback checks
- Connection monitoring and recovery tools
- Exportable diagnostic reports

### 🌡️ Cooling Assistance
- Guided T300 cooling mode instructions
- Force feedback fade reminders
- Cooling recommendations for longer sessions

### 🔄 Drivers, Firmware & Updates
- Thrustmaster driver version detection
- Driver update notifications
- Integration with Thrustmaster's official firmware updater
- GitHub-based application update checking
- Release notes and changelogs
- Optional updates with the ability to skip versions

**Important:** T300 Studio does not directly flash wheel firmware. Firmware updates are handled by Thrustmaster's official tools.

### 🎨 Personalization
- Custom accent colors
- Dark interface
- Multiple interface languages
- Customizable application preferences

## 🐛 Bug Reports & Feedback

Found a bug or have a feature suggestion?

Community feedback is extremely valuable to the development of T300 Studio.

When reporting an issue, please include:

- T300 Studio version
- Your steering wheel model
- Windows version
- Description of the problem
- Steps to reproduce it
- Diagnostic report, if available

T300 Studio includes a diagnostic report exporter that allows you to preview the information being shared.

**Please review exported reports before sharing them to ensure they contain no personal information.**
